01 / CONFIGURE & GENERATE

Signature material experiment

Four-state channel model

Each detected, matching-basis sample comes from an executed quantum circuit. Bob and Charlie receive independent simulated channels.

02 / SIGN & VERIFY

Message integrity demonstration

This public MVP uses a classical HMAC wrapper for message integrity, then checks the recipients' simulated mismatch rates. It is not a complete quantum signature scheme.

After signing, change the message and verify again to demonstrate tampering detection.

03 / CONTROLLED INTERFERENCE

Intercept and resend

Eve intercepts a chosen fraction of signals, measures in a random basis, and sends the resulting state onward. Bob and Charlie check a random test sample for errors.

04 / COMPARE EXPERIMENTS

Use the same configuration and seed at each intensity. Finite samples fluctuate; this graph compares measured test errors with the model's expected curve.

05 / UNDERSTAND THE SAMPLE

Hoeffding sampling bound

Estimate how far a sampled error rate may be from its expected value under independent-observation assumptions. This calculation is not a QDS security proof.

06 / EXECUTE ON QISKIT AER

See the quantum circuit

Alice prepares |0⟩, Eve measures in the X basis, and Bob measures in Z. For this fixed wrong-basis example, Bob's error rate is approximately 50%. In a full random-basis intercept-resend sweep it is approximately 25% at zero baseline noise.

This is an independent public teaching implementation. Full QDS protocols, security proofs, optical coherent-state models, hardware execution, and QML are outside this MVP.
